# Nexo

Local delivery planning, hierarchical tasks, dependency graphs and live agent ownership for Claude Code.

Requires Node.js 24.22.x and Claude Code 2.1.316 or later. Install the marketplace with /plugin marketplace add heamaral/nexo-claude, then /plugin install nexo@nexo-marketplace. In a project, run /nexo:init, /nexo:plan and /board.

Release candidate 1.0.0-rc.4. The runtime and browser UI are bundled. The UI is currently Portuguese; agents respond in the user's language. Read the repository README, security boundaries and release criteria before adoption.
